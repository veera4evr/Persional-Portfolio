# Veera's Verse - Personal Portfolio ✨

A premium, interactive personal portfolio website showcasing my skills, projects, and professional background as a Full-Stack Developer and Creative Technologist. 

Built with modern web technologies, this portfolio features smooth animations, glassmorphism aesthetics, and a fully responsive design tailored for exceptional user experience.

## 🚀 Features
- **Cinematic Preloader**: Custom-built smart loader with simulated network progress and smooth SVG logo animation.
- **GSAP Animations**: Buttery smooth scroll-triggered animations and reveals.
- **Lenis Smooth Scrolling**: Custom smooth scroll integration optimized for desktop and mobile touch devices.
- **Dynamic 3D-like Interactive Elements**: Includes tilting project cards, glowing ambient effects, and interactive UI components.
- **Fully Responsive**: Optimized seamlessly across mobile, tablet, and desktop viewports.
- **Production Ready**: SEO-optimized, code-split, and minified using Vite's highest performance settings.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS (Glassmorphism & Neon Themes)
- **Animations**: GSAP (GreenSock Animation Platform)
- **Scrolling**: Lenis Smooth Scroll
- **Icons**: FontAwesome & Lucide React
- **Routing**: React Router DOM

## 💻 Local Development

Clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/veera4evr/Persional-Portfolio.git

# Navigate to the directory
cd Persional-Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 🏗️ Building for Production

To create a production-ready build:

```bash
# Generate the build
npm run build
```
The optimized files will be output to the `dist` directory, ready to be deployed to any static host (Hostinger, Netlify, Vercel, etc.). 

*(Note: The build is already configured for Apache/LiteSpeed SPA routing via a custom `.htaccess` file).*
